# FileMaker-Entwicklung · Python · SQL

Anwendungsentwickler aus Aachen mit Schwerpunkt **Claris FileMaker**. Seit 2020 entwickle ich beruflich FileMaker-Lösungen, zuerst als Werkstudent, heute in Vollzeit: von der Planung über Schnittstellen und Sonderprogrammierungen bis zur Fehleranalyse und Qualitätssicherung.

Nebenbei vertiefe ich Python und SQL und probiere aus, wie sich FileMaker mit Webtechnik flexibler machen lässt.

## Warum hier wenig FileMaker-Code liegt

Der Großteil meiner Arbeit steckt in Kundenlösungen, die nicht öffentlich sind, und in `.fmp12`-Dateien, die auf GitHub kaum lesbar sind. Hier zeige ich deshalb eigene Projekte, bei denen Konzept, Designentscheidungen und die textbasierten Anteile im Vordergrund stehen.
